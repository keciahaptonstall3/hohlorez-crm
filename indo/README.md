# INDO CRM

Telegram-бот и мини-приложение поверх таблицы «Заявки — автоматическая копия».

- `Code.gs` — сервер на Google Apps Script: бот (webhook) и API мини-приложения.
- `index.html` — мини-приложение, открывается на GitHub Pages: `https://keciahaptonstall3.github.io/hohlorez-crm/indo/`.

Лист «Заявки» только читается. Итоги звонков, перезвоны и комментарии пишутся в лист «CRM», доступ задаётся в листе «Доступ» (Telegram ID и имя).

## Запуск

1. В @BotFather создать бота, скопировать токен.
2. В таблице: Расширения → Apps Script, вставить `Code.gs`, в `CFG.BOT_TOKEN` вписать токен.
3. Развернуть → Новое развёртывание → Веб-приложение: запуск от «Меня», доступ «Все». Скопировать ссылку `/exec` в `CFG.WEBAPP_URL`, сохранить.
4. Выбрать функцию `setup` и нажать «Выполнить» (разрешить доступ). Появятся листы «CRM» и «Доступ».
5. Каждый (менеджер и руководитель) пишет боту `/start`, бот отвечает его Telegram ID. Вписать ID и имя в лист «Доступ», снова `/start`.

После правок кода: Развернуть → Управление развёртываниями → карандаш → Версия «Новая», чтобы ссылка `/exec` не менялась.
